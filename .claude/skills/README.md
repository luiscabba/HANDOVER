# Skills

Copy these folders into `~/.claude/skills/`, or open this repo in Claude Code, which loads `.claude/skills/` automatically.

| Skill | Use it for |
|---|---|
| `sbc-capital-brief` | Start of any SBC thread |
| `gusto-caffe-brief` | Start of any Gusto thread |
| `screen-purpose-pass` | Define who a screen is for and its one job, before design |
| `reference-study` | 6 to 8 real references, captured and compared, before designing |
| `divergent-variations` | Making options that are genuinely different styles |
| `design-taste-frontend` | Building pages that do not look templated |
| `impeccable` | Critique, audit and polish of a built interface (third-party: Paul Bakaus's Impeccable) |
| `design-rationale-canvas` | Walking a client from findings to the chosen design |
| `no-ai-slop` | Tightening prose |
| `no-ai-slop-systems` | Plain names for tokens, components and headers |
| `texxen-voice` | Any copy texxen sends or publishes |
