# Gusto Caffè design

## Tokens (site v3, `site/index.html`)

| Role | Value |
|---|---|
| Background, deep | `#0F0906` |
| Espresso | `#1C120B`, `#2A1D13` |
| Text on dark | `#EDE3D1` |
| Cream, latte | `#F6F0E5`, `#ECE2D1` |
| Gold | `#C9963F` |
| Flag green, red (hairline accents only) | `#0B7A41`, `#A8232B` |
| Muted | `#B9A88E`, `#6B5A49` |

Type: Bodoni Moda (display), Figtree (body). Arabic: Noto Naskh Arabic (display), IBM Plex Sans Arabic (body).

These follow the O2.2 skin. Expect the palette to shift once the cursive logo is picked; keep the dark espresso tone.
